何梅岑（1906-1982年）

![image](/assets/imgs/hemeicen.jpg "何梅岑（右一）與大辭典編纂處人員合影"){: width="300" }

因其家學而博學，治學嚴謹，在歷史方面造詣很深。他曾為《文史（上海）》特邀撰稿人，並在中國現代文學期刊上發表過文章。

長期在[中國大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})擔任編纂員，參與了以下辭書的編纂工作：

- 《[國語辭典]({{ site.baseurl }}{% link glossary/national-language-dict-tw.md %})》（全八冊） 汪怡主編，徐一士、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、彭心如、徐世榮、何梅岑、[傅嚴]({{ site.baseurl }}{% link people/fuyan-tw.md %})、[牛文青]({{ site.baseurl }}{% link people/niuwenqing-tw.md %})編纂 商務印書館印行（1945年）
- 《國語辭典》（全四冊） [黎錦熙]({{ site.baseurl }}{% link people/lijinxi-tw.md %})主編，[汪怡]({{ site.baseurl }}{% link people/wangyi-tw.md %})（主任）、徐一士、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、徐世榮、[傅嚴]({{ site.baseurl }}{% link people/fuyan-tw.md %})、[安文倬]({{ site.baseurl }}{% link people/anwenzhuo-tw.md %})、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、張蔚瑜、何梅岑、[牛繼昌]({{ site.baseurl }}{% link people/niuwenqing-tw.md %})、高景成編纂 商務印書館（1948年），1962年改編再版更名為《漢語詞典》
- 《新部首索引[國音字典]({{ site.baseurl }}{% link glossary/national-pronounciation-dict-tw.md %})》 [黎錦熙]({{ site.baseurl }}{% link people/lijinxi-tw.md %})主編，[汪怡]({{ site.baseurl }}{% link people/wangyi-tw.md %})（主任）、徐仁鈺、[傅介石]({{ site.baseurl }}{% link people/fuyan-tw.md %})、[牛繼昌]({{ site.baseurl }}{% link people/niuwenqing-tw.md %})、高景成、何梅岑、徐世榮、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、張迺芝、張蔚瑜編校 商務印書館（1949年8月初版）
- 《增注中華新韻》 [黎錦熙]({{ site.baseurl }}{% link people/lijinxi-tw.md %})主編，[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、何梅岑、傅岩、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、張蔚瑜、張廼芝編校 商務印書館（1950年7月第一版）
- 《增訂注解 國音常用字彙》 [黎錦熙]({{ site.baseurl }}{% link people/lijinxi-tw.md %})主編，[汪怡]({{ site.baseurl }}{% link people/wangyi-tw.md %})、何梅岑、付介石、[牛繼昌]({{ site.baseurl }}{% link people/niuwenqing-tw.md %})、高景成、徐仁鈺、徐世榮、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、張廼之、張蔚瑜、李曾篤、諸昌祁編校 商務印書館（1949年8月初版）
- 《學文化字典》 [黎錦熙]({{ site.baseurl }}{% link people/lijinxi-tw.md %})主編，[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、何梅岑、高景成、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、徐仁鈺、徐世榮、[傅介石]({{ site.baseurl }}{% link people/fuyan-tw.md %})編纂 商務印書館（1952年10月第一版）
- 《同音字典》 [黎錦熙]({{ site.baseurl }}{% link people/lijinxi-tw.md %})主編，何梅岑、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、徐世榮、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、高景成、傅嚴編纂 商務印書館（1956年5月第一版）

1956年7月，在中國科學院語言研究所詞典編輯室任編輯，參與《現代漢語詞典》（試印本）的編纂工作，是哲學社會組的組長。文革期間曾被下放河南「五七幹校」勞動，雖歷經坎坷但堅持學術理想。1982年8月，因急性腎炎去世，享年76歲。學界對其評價極高，社科院語言所曾獻輓聯「學富五車一生節槪媲先哲，家徒四壁數卷辭書傳後昆」，肯定其人品與學識。
