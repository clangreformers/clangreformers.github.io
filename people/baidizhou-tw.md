白滌洲（1900年5月5日-1934年10月12日），北平人，名鎮瀛，別名獲舟，以字行，其先出自蒙古白濟特氏，清代隸鑲藍旗。

![image](/assets/imgs/baidizhou.jpg "白滌洲"){: width="300" }

![image](/assets/imgs/baidizhou_and_friends.jpg "白滌洲（右三）與友人"){: width="300" }

1915-1920年，白滌洲在北京師範學校學習，他艱苦自勵，每試輒列前茅。畢業後，他先後在京師公立第十七高等小學（現北京方家胡同小學）和第七高等小學（位於西單牌樓南宗學胡同）任校長。

1924年，考入北京大學預科，同時在北京教育會辦理會務。1926年入北京大學英文系讀本科，1928年轉入國文系，從師於錢玄同、馬幼漁、劉半農等人專治聲韻和語音學。他曾參加中央研究院歷史語言研究所語言訓練班，從師於趙元任學習聽寫方言。

1930年畢業於北京大學國文系，後任北平市立師範學校（即首都師範大學）教務主任。

1933年10月，應劉半農之邀，任北京大學研究所文史部語音樂律實驗室助教。

白滌洲是[國語運動]({{ site.baseurl }}{% link glossary/movement-tw.md %})的積極參與者，他為國語運動作了大量工作：

1919年4月，[國語統一籌備會]({{ site.baseurl }}{% link glossary/preparation-tw.md %})成立，他被聘為會員。

1920年，白滌洲在國語講習所研究國音，被黎錦熙相中，邀請他共同致力於國語運動。1923年與黎錦熙同赴杭州傳習國語。

1928年國語會改組為國語統一籌備委員會，他先後任委員、常務委員。任職期間他多次前往外地視察國語推廣工作。他在常務委員任上先後提案16個，包括建議編印民眾讀物、審定各種國語教科書、請鐵道部及交通部提倡國音電報、推行注音符號、調查各地方言等。

同年，白滌洲任[中國大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})整理部主任。數年間，他先後整理卡片20萬張，完成了近20項研究工作。國音字母講習所成立後，他任教務主任，並親自授課。

1931年9月5日，國語會機關刊物《國語周刊》（《世界日報》附刊）創刊，白滌洲與何兆熊共任主編。

1932年底至1933年1月，白滌洲遭遇妻子、三個孩子及父親相繼離世的巨大家庭變故。1933年3月，傅斯年邀他調查豫、晉、秦、隴之入聲變讀情況，他即赴陝西調查方言至8月中旬。期間，他調查了關中四十二個縣五十個點的方言，留下大量調查材料。這部分材料由羅常培保存，喻世長整理，在1954年以《關中方音調查報告》為名出版。

1934年暑期，白滌洲隨劉半農赴歸綏調查方言，歷時三周。歸來後劉半農因染回歸熱病逝，白滌洲則趕赴長安代表國語會演講。9月23日，白滌洲再赴鄭州出席國語羅馬字全國代表大會。

1934年10月12日，白滌洲病逝於北平林葆駱醫院，後安葬於西山。1934年11月11日上午，國語會為白滌洲開追悼會，黎錦熙主持，錢玄同致悼詞，魏建功、羅常培及老舍等好友同仁紛紛發表文章以示紀念。

**著作與文獻**

1925年，白滌洲為平民教育促進會起草了《平民字典》稿本。1926年國語統一籌備會著手增修之《[國音字典]({{ site.baseurl }}{% link glossary/national-pronounciation-dict-tw.md %})》，1932年教育部公布之《國音常用字彙》，其初稿均出自他之手。他還應中華書局之邀，灌製了《標準國音》、《標準國語》、《小學國語讀本選讀》三套唱片。
