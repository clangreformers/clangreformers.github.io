白涤洲（1900年5月5日-1934年10月12日），北平人，名镇瀛，别名获舟，以字行，其先出自蒙古白济特氏，清代隶镶蓝旗。

![image](/assets/imgs/baidizhou.jpg "白涤洲"){: width="300" }

![image](/assets/imgs/baidizhou_and_friends.jpg "白涤洲（右三）与友人"){: width="300" }

1915-1920年，白涤洲在北京师范学校学习，他艰苦自励，每试辄列前茅。毕业后，他先后在京师公立第十七高等小学（现北京方家胡同小学）和第七高等小学（位于西单牌楼南宗学胡同）任校长。

1924年，考入北京大学预科，同时在北京教育会办理会务。1926年入北京大学英文系读本科，1928年转入国文系，从师于钱玄同、马幼渔、刘半农等人专治声韵和语音学。他曾参加中央研究院历史语言研究所语言训练班，从师于赵元任学习听写方言。

1930年毕业于北京大学国文系，后任北平市立师范学校（即首都师范大学）教务主任。

1933年10月，应刘半农之邀，任北京大学研究所文史部语音乐律实验室助教。

白涤洲是[国语运动]({{ site.baseurl }}{% link glossary/movement-cn.md %})的积极参与者，他为国语运动作了大量工作：

1919年4月，[国语统一筹备会]({{ site.baseurl }}{% link glossary/preparation-cn.md %})成立，他被聘为会员。

1920年，白涤洲在国语讲习所研究国音，被黎锦熙相中，邀请他共同致力于国语运动。1923年与黎锦熙同赴杭州传习国语。

1928年国语会改组为国语统一筹备委员会，他先后任委员、常务委员。任职期间他多次前往外地视察国语推广工作。他在常务委员任上先后提案16个，包括建议编印民众读物、审定各种国语教科书、请铁道部及交通部提倡国音电报、推行注音符号、调查各地方言等。

同年，白涤洲任[中国大辞典编纂处]({{ site.baseurl }}{% link glossary/compilation-cn.md %})整理部主任。数年间，他先后整理卡片20万张，完成了近20项研究工作。国音字母讲习所成立后，他任教务主任，并亲自授课。

1931年9月5日，国语会机关刊物《国语周刊》（《世界日报》附刊）创刊，白涤洲与何兆熊共任主编。

1932年底至1933年1月，白涤洲遭遇妻子、三个孩子及父亲相继离世的巨大家庭变故。1933年3月，傅斯年邀他调查豫、晋、秦、陇之入声变读情况，他即赴陕西调查方言至8月中旬。期间，他调查了关中四十二个县五十个点的方言，留下大量调查材料。这部分材料由罗常培保存，喻世长整理，在1954年以《关中方音调查报告》为名出版。

1934年暑期，白涤洲随刘半农赴归绥调查方言，历时三周。归来后刘半农因染回归热病逝，白涤洲则赶赴长安代表国语会演讲。9月23日，白涤洲再赴郑州出席国语罗马字全国代表大会。

1934年10月12日，白涤洲病逝于北平林葆骆医院，后安葬于西山。1934年11月11日上午，国语会为白涤洲开追悼会，黎锦熙主持，钱玄同致悼词，魏建功、罗常培及老舍等好友同仁纷纷发表文章以示纪念。

**著作与文献**

1925年，白涤洲为平民教育促进会起草了《平民字典》稿本。1926年国语统一筹备会着手增修之《[国音字典]({{ site.baseurl }}{% link glossary/national-pronounciation-dict-cn.md %})》，1932年教育部公布之《国音常用字汇》，其初稿均出自他之手。他还应中华书局之邀，灌制了《标准国音》、《标准国语》、《小学国语读本选读》三套唱片。
