《国语小报》是台湾《国语日报》的前身，由中华民国教育部委托中国大辞典编纂处办理，推动此事的关键人物是黎锦熙。1947年1月15日，《国语小报》在北平创刊，其报头由时任国语会主任吴敬恒题写，黎锦熙为“国语小报”四个字标注了注音符号，并撰写了《发刊词》。

《国语小报》为小型四开三日刊，全文配有注音符号是它最独到的特色。报纸内容丰富，包括国语教学专栏、国内外新闻摘要、北平本地民生专栏、教育界信息（教育局政令、中小学活动、民众教育馆扫盲班通知等）、通俗副刊、白话故事、科普、劝善短文以及读者问答等。其主要发行方向为各公立学校与民众教育馆免费发放，并在街头报摊低价零售，或由教育局及各教育单位订阅。

《国语小报》具有以下几个鲜明特点：
1. **内容**：充实扼要，以少胜多；
2. **文字**：完全白话，老妪都解；
3. **编制**：依照数码，有条不紊；
4. **排印**：逐字注音，词类连书；
5. **副刊**：初有五种，后续续增。

《国语小报》的兼任社长和发行人为时任国语会常委[萧家霖]({{ site.baseurl }}{% link people/xiaojialin.md %})，编印主任为[王寿康]({{ site.baseurl }}{% link people/wangshoukang.md %})。报社的办公地点位于北平西单南大街甲169号。由于国民政府财政困难，《国语小报》最初批准的编制仅有徐世荣和樊月培二人。报社资产仅有对开和四开印刷机各一台，印刷用的二、三、五号注音国字铜模及手摇铸字机均是借用自[中国大辞典编纂处]({{ site.baseurl }}{% link glossary/compilation-cn.md %})。在编纂处工作的[王述达]({{ site.baseurl }}{% link people/wangshuda.md %})、[孙崇义]({{ site.baseurl }}{% link people/sunchongyi.md %})、[张洵如]({{ site.baseurl }}{% link people/zhangxunru.md %})、何梅岑等人都积极为报纸供稿。根据1948年4月的职工名册，报社包括工役在内共有36人。

1948年1月，教育部部长朱家骅决定将《国语小报》迁至台湾并改为日刊。同年6月，教育部下达指令，指示[国语推行委员会]({{ site.baseurl }}{% link glossary/committee-cn.md %})专任委员何容将《国语小报》移台并改组为《国语日报》，经费和编制自7月起转至台北。在北平发刊178期后，《国语小报》于1948年7月正式停刊，随后在台湾以《国语日报》的形式继续出版。
