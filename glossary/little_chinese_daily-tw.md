《國語小報》是臺灣《國語日報》的前身，由中華民國教育部委託中國大辭典編纂處辦理，推動此事的關鍵人物是黎錦熙。1947年1月15日，《國語小報》在北平創刊，其報頭由時任國語會主任吳敬恆題寫，黎錦熙為「國語小報」四個字標註了注音符號，並撰寫了《發刊詞》。

《國語小報》為小型四開三日刊，全文配有注音符號是它最獨到的特色。報紙內容豐富，包括國語教學專欄、國內外新聞摘要、北平本地民生專欄、教育界信息（教育局政令、中小學活動、民眾教育館掃盲班通知等）、通俗副刊、白話故事、科普、勸善短文以及讀者問答等。其主要發行方向為各公立學校與民眾教育館免費發放，並在街頭報攤低價零售，或由教育局及各教育單位訂閱。

《國語小報》具有以下幾個鮮明特點：
1. **內容**：充實扼要，以少勝多；
2. **文字**：完全白話，老嫗都解；
3. **編制**：依照數碼，有條不紊；
4. **排印**：逐字注音，詞類連書；
5. **副刊**：初有五種，後續續增。

《國語小報》的兼任社長和發行人為時任國語會常委[蕭家霖]({{ site.baseurl }}{% link people/xiaojialin.md %})，編印主任為[王壽康]({{ site.baseurl }}{% link people/wangshoukang.md %})。報社的辦公地點位於北平西單南大街甲169號。由於國民政府財政困難，《國語小報》最初批准的編制僅有徐世榮和樊月培二人。報社資產僅有對開和四開印刷機各一臺，印刷用的二、三、五號注音國字銅模及手搖鑄字機均是借用自[中國大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})。在編纂處工作的[王述達]({{ site.baseurl }}{% link people/wangshuda.md %})、[孫崇義]({{ site.baseurl }}{% link people/sunchongyi.md %})、[張洵如]({{ site.baseurl }}{% link people/zhangxunru.md %})、何梅岑等人都積極為報紙供稿。根據1948年4月的職工名冊，報社包括工役在內共有36人。

1948年1月，教育部部長朱家驊決定將《國語小報》遷至臺灣並改為日刊。同年6月，教育部下達指令，指示[國語推行委員會]({{ site.baseurl }}{% link glossary/committee-tw.md %})專任委員何容將《國語小報》移臺並改組為《國語日報》，經費和編制自7月起轉至臺北。在北平發刊178期後，《國語小報》於1948年7月正式停刊，隨後在臺灣以《國語日報》的形式繼續出版。
