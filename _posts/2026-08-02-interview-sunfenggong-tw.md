作者：王昀

*謹以此文紀念孫崇義先生誕辰120週年*

孫奉公是[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})先生的長子，他和夫人謝景懿退休前都是中學老師，如今雙雙邁入80後的行列。採訪他們是在一個又悶又熱的上午，我沒敢開車。他們居住的牛街西里小區是二十世紀末牛街拆遷的回遷樓，這裡平均十幾戶人家才能攤上一個不太正規的停車位。回遷樓的標準很低，樓道窄小昏暗，地面和牆面不僅沒有任何裝修而且已然斑駁。孫家的門側與眾不同地掛著"懿行堂書齋"的小牌子。孫老師為我開了門，謝老師腿腳不好，也起身招呼我坐在了上座。剛落座，謝老師已經給我倒上熱茶，茶几的托盤上，一隻玻璃茶壺、一個玻璃茶杯透出溫暖的茶湯。房間涼爽舒適，原來他們既開了空調也開了窗。

孫老師耳背，戴了助聽器，他特意坐在我和謝老師對面的一個圓凳上。就這樣，孫老師一邊側耳傾聽我的問題，一邊大聲講述起他父親[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})的往事。謝老師則不時作些補充、解釋或糾正。

在我上小學時，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})先生常來我家，他是我祖父的同事和好友。他總是戴著一頂白色的禮拜帽，並且從不喝祖母倒的茶水。這是我那時對穆斯林的全部理解。而今天的採訪讓我耳目一新，他們知書而達禮，謙遜而感恩，他們把自己所得都歸於真主所賜，他們的信仰是指導他們前行的動力。在他們的講述中，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})（字謂宜，號榴堂老人，經名葉海亞，1906-1997年）的故事是圍繞著他的三位恩人展開的。

第一位恩人孫曜（字幼銘，號牖民，1891-1938年）是[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})的五叔。這就要從孫家的家世講起了。孫家祖籍南京，明清時溯運河北上至臨清。那時的臨清扼南北漕運咽喉，商賈雲集，大量回族人在此生活。清末，運河淤塞、津浦鐵路通車，漕運廢止，臨清衰落。孫家隨著人潮到了北京，落腳在回族聚居的牛街。孫家並不是書香門第，而是做"羊行"的，也就是賣牛羊肉。大家庭最早的讀書人就是孫幼銘，他早年從政，在民國國會服務多年，後在中華書局、《新晨報》、《北平晨報》做編輯，算是出版界"晨報系"的主要成員。1929年11月5日，《月華》旬刊由北平成達師範學校創辦，孫幼銘受邀兼任主編至1931年秋，這一雜誌是近代中國所有回族刊物中歷時最久、影響範圍最廣、也最具代表性的報刊。孫幼銘活躍在京城回民文化圈，他還曾與孫繩武、馬松亭等發起創辦學校，他的信條是"剛正不阿，勤學敬業"。

孫宅位於北京牛街沙欄兒衚衕西口的一個高臺階上，堂屋北牆上懸掛著孫幼銘書寫的一副對聯："沙上錐鋒覘筆妙，水中鹽味司詩禪"，這正是孫家的座右銘。孫幼銘精通漢學，擅詩詞，工篆刻，對書法情有獨鍾。他利用院內遊廊創設"棠蔭塢書齋"，室內書香繚繞，室外海棠幽深，正是讀書的好地方。五叔孫幼銘立下規矩，家庭中所有的孩子都要在此讀書，他在百忙之餘也會來監督、陪讀。幼年[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})每天放學後就坐在這裡，與同輩的崇莞、崇仁及晚輩的奉來等一起看書寫字。九十歲時，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})仍能栩栩如生地講起當年五叔在這裡講過的故事，後來他能在小學畢業後即考入北平市市立師範學校，其文言功底大多來自"棠蔭塢"這個家塾以及孫幼銘這位家長。要知道，當年這個學校考取難度不亞於北師大附中，因為學校不僅管吃管住還分配工作。也正是這個原因，家境平平的[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})選擇了這所學校。二十世紀五十年代，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})在中國科學院語言研究所工作時，丁聲樹曾讚歎他寫的字"有家傳"。這家傳來自孫幼銘，他曾以史學家的角度透析了歐體書法的獨到之處，在保持歐體遒勁、穩健的風格上，相容個人審美，使剛勁與平和融為一體，達到和諧統一。他矢志不渝地將這一書法在家族內推廣，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})因此受益，寫得一筆漂亮的歐體字，他曾用此為龐士謙阿訇的《埃及九年》題寫書名。

第二位恩人是牛街清真寺的阿訇王寬（字浩然，經名阿卜杜·拉赫曼，1848-1919年），他是近現代中國宗教教育革新家。1907年，王寬在北京牛街清真寺後院創辦了新型的迴文師範學堂。1908年，他又創辦了京師清真兩等小學堂，這是中國歷史上第一所專門為穆斯林子弟設立的伊斯蘭小學，回族孩子從此有了讀書和改變命運的機會。因辦學成功，學校在[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})就讀時已改為京師公立第二十小學校。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})記得他上小學一年級時，王寬阿訇在庭院裡給學生們訓話。他講了1906年到麥加朝覲後受到奧斯曼帝國的蘇丹（阿卜杜勒·哈米德二世）的接見，講他們談及提高中國穆斯林素質和學習中國傳統漢文化，講到要以此振興中國經濟。也就在這一天，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})立志認真學好中國文化，這成為他一生致學的起點。

第三位恩人是[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})在北師大的老師黎錦熙先生。二十世紀五十年代，教育部與中科院語言研究所聯合舉辦了三期普通話語音研究班，牽頭人丁聲樹是中央研究院的院士，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})被安排擔任具體教學、指導工作，當他把自己寫的教學計劃和教案交丁聲樹審閱時，丁聲樹表示了極大的信任："不用看了，咱們都是錢玄同先生的弟子，你還是黎錦熙先生的高足……"由此可見黎錦熙先生對[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})的影響之深刻。1930年，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})考入嚮往已久的北平師範大學，在錢玄同、黎錦熙等名師的指導下完成學業並進入北師大附中教書。在他讀大學時，[國語運動]({{ site.baseurl }}{% link glossary/movement-tw.md %})正如火如荼地開展，就讀於北師大即置身這一運動的核心。作為國文系的學生，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})深受感召。黎錦熙很器重他，直接把他安排到[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})工作，使他得以與眾多國語專家、學者共事。

在1935年3-6月，為鑄造注音漢字銅模，先由九種字彙和三種打字機列表中得來五萬多字，再從中選定常用字。當時參與此事的有17人，其中黎錦熙、錢玄同、[汪怡]({{ site.baseurl }}{% link people/wangyi-tw.md %})、[陳懋治]({{ site.baseurl }}{% link people/chenmaozhi-tw.md %})、魏建功、趙元任、[蕭家霖]({{ site.baseurl }}{% link people/xiaojialin-tw.md %})、[沈頤]({{ site.baseurl }}{% link people/shenyi-tw.md %})、陸基、李步青、孫世慶為國語會委員，徐一士、彭望群、張蔚瑜、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、陸秀如和[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})來自[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})。最終，大家以投票方式確定了6788個常用字作為鑄造銅模的藍本。常用字表不僅是印刷鑄造的依據，也對編纂字典和教科書具有指導意義。錢玄同日記中可以印證此事。1935年4月30日："午後歸家一行，即至某海（注：這是錢玄同對中海的稱呼），為注音銅模事，汪、黎二公主張將一字數音者能減少鑄造數最佳。約[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、王善愷，甚至如趙善齋等共作顧問，而汪、黎、錢三人決定之……孫、王二人系大學畢業尚可備顧問，趙善齋何至竟不如[白滌洲]({{ site.baseurl }}{% link people/baidizhou-tw.md %})乎？"能得到錢玄同的認可實屬不易。5月4日："午後至某海，黎、汪、王、孫四人正商選銅模字事，我亦參加焉。"

大學畢業後的[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})為自己買了一輛假冒飛利浦腳踏車。正宗的飛利浦車在當時屬英國洋貨，假冒的則為拼裝貨。他可不是為了趕時髦，他和眾多民國教書匠一樣，開啟了趕鐘點的教書生涯。除了師大附中，他也在師大女附中、女三中等校代課。一方面，他熱愛教書，總希望多些實踐機會；另一方面，那時中學教員薪資不高，加之民國政府財政困難，學校欠薪嚴重，為維持家用和自己學術研究購書等的需求，這樣的生活是他們的常態。

後來，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})在北平師範學院（即北京師範大學）做過講師，又在文字改革委員會、中國科學院語言研究所工作過，最終在河北北京師範學院（後改為河北師範大學）中文系任教並終老。他是中國最重要的兩本辭書《國語辭典》和《現代漢語詞典》的主要編纂人，也是桃李滿天下的教授，可謂學有所成。而談起這些，他總是把自己的成就歸功於恩師黎錦熙先生。1951年5月，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})加入了九三學社，成為該社最早的會員，這是以科學技術和文教界中/高階知識分子為主的政治聯盟，他的介紹人也正是黎錦熙。

如果僅存感恩，那生命的意義未能彰顯，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})用他的努力踐行了自己的回饋之路。

小學畢業進入北平市市立師範學校，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})就開始了獨立和自我成長。住在學校裡，每個月只要發下生活費，他馬上交到旁邊的早點鋪。他在那裡入夥，和小夥計一起吃飯，不管好賴，總能餬口。1926年，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})以優異的成績畢業，學校分配他去北平圖書館任職員，他卻選擇前往石家莊的扶輪小學任教。為此，孫幼銘當年信札中有："崇義以英年處約境，志趣尚正，吾家後起之秀，臨行，餘教以隨時留意當地狀況，載之筆記，積久可為習用之物。"五叔的期待和教誨躍然紙上，而[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})也謹記慎行，他終生養成寫日記和記筆記的好習慣。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})離家是有自己打算的，扶輪小學隸屬於京漢鐵路，待遇頗豐。在那裡，他每月能掙到六塊大洋。他會寄三塊給家裡，自己花兩塊再存一塊。就這樣，工作三年存夠了上大學的錢，他毅然辭職，準備繼續深造。

當他回到北平之際，恰逢成達師範學校從濟南遷至北平，《月華》雜誌和北平清真中學（1931年更名為北平西北公學）創辦，孫幼銘擔任總編和學校董事。應五叔之邀，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})開始向《月華》雜誌投稿。他還與牛街的王夢揚等回族青年依託北平清真書報社所屬"追求學會"，以筆名發表文章，旨在傳播伊斯蘭文化，擴大穆斯林知識視野並推動伊斯蘭經典的漢語翻譯和現代傳播。

在北師大畢業後，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})努力把自己塑造成像孫幼銘一樣的人，終生置力於教育、學問和服務社會。他和五叔一起成為牛街最著名的學者，這不得不說是對五叔最好的回饋。1991年[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})聽說牛街老宅要拆遷，鉤起[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})對五叔的思念，他寫下一首七律《棠陰塢》贈予五叔的兒子孫崇莞夫婦，思念與眷戀溢於其中："斗室營成為屬文，暑天走筆構思勤，棠陰滿院雲天渺，無限淒涼憶舊芬。"

[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})是一位虔誠的穆斯林，每天的禮拜是他必修的功課。他最常去的清真寺是位於他工作地點附近的西單清真寺和位於老宅附近的牛街清真寺。在這裡，他結識了許多回族名人。他喜歡發揮自己的語言專長，用不同方言與他們對話。比如阿訇龐世謙和史學家白壽彝都是河南人，卻是不同地區的，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})能夠把河南話也講出區別來，令大家佩服不已。不過這種交往並不僅是社交，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})始終不忘王寬阿訇辦學成就了他，他希望為回民的教育儘自己的微薄之力。1947年初，由馬松庭大阿訇和龐世謙阿訇在北平東四清真寺建立了北平回教經學院，培訓全國各地的阿訇。阿訇既是教長，也是回民學校的校長和醫協會長，這"三長"在各地回民中影響深遠。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})不僅在學院擔任教職，他還利用這個機會推廣國語。這得到了[國語推行委員會]({{ site.baseurl }}{% link glossary/committee-tw.md %})的支援，特委派[何梅岑]({{ site.baseurl }}{% link people/hedanjiang-tw.md %})、徐世榮等前去開展國語培訓。後來，馬松庭想把這個學院辦成回民的大學，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})很贊同，特撰寫辦學宣言。由於政府更迭，經學院停辦，在讀的學生部分進入北京大學東語系繼續深造，部分轉入華北人民革命大學，成為阿拉伯語系的外交人員。這些人後來在各領域和各地穆斯林中發揮著重要的作用。

[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})對黎錦熙先生的知遇之恩是以蠟炬成灰的方式相報的。抗戰爆發後，黎錦熙等師生、國語同人紛紛南下或西去，已有家小的[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})仍留在北平。他的夫人王溶華也畢業於北京師範學校，是小學教員。"七七"事變後，北師大附中被日本人佔為養馬場，學校一度停課。[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})的工作卻從未停止。這一點在錢玄同日記中也有表述。1937年9月17日："十三時半至某海，晤周、汪老、汪少、孫渭宜、王善諸人。十八時出海。"1938年10月5日："上午十一時至中海，晤小汪、回孫。"錢玄同因身體原因被困在北平，當時[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})是他最常去的地方。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})也曾在回憶文章《錢老師給我的印象》中寫道："錢老師躺在帆布椅子上，口講指畫的談著，也有國家大事，也有私人生活，也有學問思想……七七事變爆發了，錢老師感到極度的悲憤，逢人就談論著我國沒有國防的危險和淪陷區前途的可怕。"

應該說，抗戰時期在淪陷區的堅持實在是一件艱難的事情。一方面，北平人的生活條件十分艱苦，糧食匱乏，只能吃上摻著沙子的混和麵。遇到燈火管制還要使用煤油燈；另一方面，屈辱更是陪伴著有良知的人。出入城門要向日本兵行禮，三天兩頭"慶祝"各地的淪陷。中南海掛上了"中華民國臨時政府"的牌子，西四所的[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})也被偽政府以編纂教科書為由要求佔用。這時，國民政府已無法正常運轉，編纂處的經費也得不到保證。1937年初《國語辭典》只完成了第一冊的出版，人員就四散了。在[汪怡]({{ site.baseurl }}{% link people/wangyi-tw.md %})的帶領下，徐一士、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、彭心如、徐世榮、[何梅岑]({{ site.baseurl }}{% link people/hedanjiang-tw.md %})、[傅嚴]({{ site.baseurl }}{% link people/fuyan-tw.md %})、牛文青和[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})靠預支版稅等的收入，完成了《國語辭典》（八本版）的編纂和出版工作。遺憾的是，由於地處淪陷區，字典被烙上了殖民烙印，收錄了大量日本詞彙。在1947年11月21日的《大公報（天津）》上，《國語辭典》的編纂人集體署名發表了《答高名先生評"國語辭典"》一文，寫道："本來這部辭典在編排、組織等方面不過是草創試驗，正不知有幾多缺陷，需要改進；尤其牠出版在極端變態的時節，極端特殊的地域，更不知有多少事與願違之處，我們不願消極地求社會原諒，卻要積極地請社會指摘。"由此可見，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})他們這群編纂人在困境中依然堅守傳播國語的責任是多麼不容易。這幾個人除[汪怡]({{ site.baseurl }}{% link people/wangyi-tw.md %})、徐一士、[何梅岑]({{ site.baseurl }}{% link people/hedanjiang-tw.md %})和彭心如外均為黎錦熙先生的學生，他們的堅持不僅是對國語事業的熱愛，更是對恩師理想的守護。

抗戰勝利後，歸平的黎錦熙做了北平師範學院的教務長，他馬上把[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})劃歸師範學院管理。在黎錦熙的組織下，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})等幾位同仁在"八本版"的基礎上，最終完成了《國語辭典》（四本版）的編纂出版工作。這一辭典是[國語運動]({{ site.baseurl }}{% link glossary/movement-tw.md %})最重要的成果，它成為全球現代漢語標準的基石，在臺灣延用至今。1947年，黎錦熙在北平師範學院辦起國語專修科，以培養急需的國語高階專業人員，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})應邀擔任講師。後來，臺灣要求向其派送畢業生，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})又擔當考官，為他們選拔國語人才，赴臺的這批學生成為臺灣推廣國語的棟樑。

然而1949年的變動竟使[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})的人員大約有五年的時間幾乎無事可做，這正是[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})等人的黃金年齡，而評級之類的事情更輪不上他們。這時，有人開始主動尋求其他工作而離開，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})則一直跟著黎錦熙先生，一面完成了《學文化字典》、《同音字典》等幾本小型字典的編纂，一面參與北師大教學研討等工作，一面輔助黎錦熙先生在文字改革等方面的事務。1955年，根據機構調整，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})等人轉入文字改革委員會，1956年再轉入中國科學院語言研究所詞典編輯室，開始著手《現代漢語詞典》的編纂工作。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})是《現代漢語詞典》（試印本）的主要編纂人之一，他還是第二組的組長。這本字典經歷數十年，至今仍是中國大陸語文學習和教學的圭臬。與此同時，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})、[王述達]({{ site.baseurl }}{% link people/wangshuda-tw.md %})、[何梅岑]({{ site.baseurl }}{% link people/hedanjiang-tw.md %})、傅介石還參加了漢語拼音方案制定的研討工作，聯名在《光明日報》專刊《文字改革》第53期上發表了《對"漢語拼音方案（草案）"的意見》。

1962年，考慮到語言研究所再無大型辭典的編纂計劃，黎錦熙先生安排[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})等到河北北京師範學院中文系任講師。這時，很多他們的晚輩都已經成為教授，而[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})並未計較這些，他表示自己喜歡教書。

[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})對黎錦熙先生十分尊重，黎錦熙先生不僅在工作中而且在生活上也依仗於他。黎錦熙有兩位夫人，周旋其中總會有令人難辦的事情。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})擔當起牽線人，他不僅是傳信的郵差，還負責解釋和疏導，取得兩位夫人的信任，為黎家的和睦相處做了穿針引線之人。

[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})的感恩回饋，還體現在他以平常心對待所有的坎坷與不公上。在外人眼裡，很多不公平都曾發生在他身上，他的夫人就嗔怪過："你們這幾個真是一幫傻老頭，什麼也不爭不搶，全認了……"她說的就是[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})和他在[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})的幾位故交。戰爭年代的事自不必談，和平以後，當別人忙於定級享受待遇時，他們因為編制問題而被擱置。在隸屬於文字改革委員會時[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})曾被定為高階編輯（屬副高階），他去河北師院時院方曾許諾晉升為教授，實際卻又做回了講師，並且原在語言所享受的住房補貼每月十五元也被取消，當時這相當於一個大學生一個月的伙食費。1962年經濟困難，政策收緊，晉升被凍結。[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})毫無怨言，照舊工作。這正是他們這批老知識分子愛國敬業的可貴之處。接著就是文革十幾年的停頓，至1977年底才恢復職稱評定等制度，那時[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})已是古稀之年了。

1969年，河北師院按國家的要求疏導去了宣化，在距市區6公里的洋河灘上建起的四個院落成為他們的新校址。房子是一排一排的平房，全部都是"乾打壘"，即門邊和窗邊用紅磚砌起，牆壁用土坯填充。宿舍裡沒有衛生間，沒有自來水，也沒有暖氣，浴室只在院部村才有，文學院的人要走幾里路才可以到達。宣化風很大，氣候寒冷，師生生活條件十分惡劣。當時當地群眾流傳著一個順口溜："遠看像逃荒的，近看像要飯的，仔細一看是河北師院的。"花甲之年的[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})，不僅要和大家一起參加農業勞作，因為是回民，他還不得不自己煮粥解決吃飯問題。生活的艱苦不算什麼，文革期間，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})還因莫須有的罪名被打成"反革命"，經反覆申訴，在十年後的1980年3月才得以正式平反。而當一切步入正軌，已是退休之年的[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})又以滿腔熱情投入教學和研究工作。他加入了1980年成立的中國語言學會，又活躍在國語界。1981年7月，他重操舊業後主編的《語文知識詞典》正式出版。

龍先生是[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})帶的最後一個研究生，他畢業的時候，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})正好80歲。那時他已年老體衰不能赴石家莊河北師院上課，他就把教學放在位於北京西單西安福衚衕的家中。由於住房緊張，為了給[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})騰出一個教學空間，老伴早早拿上水和糖尿病藥，用童車推上小孫女，到周邊最寬敞的地方——電報大樓前玩耍，一呆就是兩三個小時。龍先生所學音韻學比較偏門，為完成論文答辯，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})特請來於敏等專家，確保答辯的專業和順利。

1996年[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})在九十歲生日時寫下《九十抒懷》，表達了他平靜而感恩的心緒："燕市尋常一穆民，懷清守真立吾身。兩依師館求嚴教，半世持勤育幼民。華夏興衰牽肺腑，語文研索企精純。行年九十知感主，願保斯心度晚辰。"1997年，[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})病故，留給後人無限的思念。

在孫奉公的家中，我注意到這狹小空間走道里巨大的書架，它像一座橋樑橫亙於時空之中，他們在這隻有幾十平米的陋室裡竟有2.5萬冊藏書！孫老師和謝老師退休後不僅著書寫字，還利用自己的藏書辦起了"懿行堂書齋"讀書會。他們的初衷正是秉承父親當年對王寬阿訇辦教育回報的理念，傳播真正的穆斯林文化。

孫奉公可以回憶起父親周邊的許多同事和朋友，令我十分驚訝。他說，因為他是長子，只要他在家，父親的同事或朋友來家中，他都會被父親叫出來打招呼行禮，如果沒事還會讓他做陪。由於[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})曾經住在[大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})，還曾與同事徐世祿、徐世榮兄弟一家同住。謝老師還憶起1968年他們二人結婚的婚房就是原[中國大辭典編纂處]({{ site.baseurl }}{% link glossary/compilation-tw.md %})的資料庫，那是個只有15平方米的西房，裡面櫃子的小抽屜裡有成千上萬張的卡片，這些卡片的收集數量曾達到250萬張，是歷經戰亂，大辭典編纂人的心血彙集而成，這令他們肅然起敬。

[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})的子女多承父業而從事教育文化工作，他們會在紀念日買上幾百本《現代漢語詞典》作為禮物送給親友。2024年，當他們得知我在進行[國語運動]({{ site.baseurl }}{% link glossary/movement-tw.md %})研究後，特將26本[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})先生所藏專業書籍和一本筆記贈予我。感恩與回饋，不僅是從[孫崇義]({{ site.baseurl }}{% link people/sunchongyi-tw.md %})先生，也是我從他的後人身上讀出的家庭主旋律。
